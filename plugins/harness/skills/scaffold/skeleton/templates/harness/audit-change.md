# <제목>

- 날짜: YYYY-MM-DD
- 작성자: <이름>

이 파일 하나가 변경 기록 한 건이다. 새 변경이 생길 때마다 새 파일을
`audit/changes/YYYYMMDD-<요약>.md` 로 만든다. 기록을 파일 하나에 몰아 적지
않는 이유는, 여러 사람이 같은 시각에 각자 기록해도 파일이 겹치지 않아 PR 이
충돌하지 않기 때문이다.

## 종류

요구사항 변경 / 설계 변경 / 결정 / 기타 가운데 하나를 적는다.

## 바뀐 것

바뀐 REQ 번호와 파일을 적는다. 예: REQ-012, docs/spec/구매요청.md

## 근거

왜 바뀌었는지를 적는다. 고객 요청, 회의, 기술 제약 등.

## 영향

이 변경이 영향을 주는 Spec, 진행 원장, 산출물을 적는다.

## 관련 PR

관련 PR 의 번호나 링크를 적는다.
